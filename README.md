# 📊 Modelo Predictivo de ROI: Bienestar Corporativo

Este repositorio contiene un modelo de análisis financiero desarrollado en Python para calcular el **Retorno de Inversión (ROI)** y el **Periodo de Recuperación (Payback)** de programas de cesación tabáquica en entornos corporativos.

## 🎯 Objetivo del Proyecto

Demostrar a través de **Data Science** cómo la inversión en la salud de los empleados (específicamente dejar de fumar) genera un retorno financiero tangible mediante la reducción de costos ocultos (absentismo y micro-pausas).

## 🧮 Metodología

El script utiliza `pandas` y `matplotlib` para simular tres escenarios financieros:
1.  **Conservador:** 10% de tasa de éxito.
2.  **Moderado:** 30% de tasa de éxito.
3.  **Optimista:** 50% de tasa de éxito.
